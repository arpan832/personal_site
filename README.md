## My Mistakes -

There to place things at plae like the plant photos the section i mostly used hardcoded position using **Relative or Absolute** attributes and fixed Width and height all over the places now what happend was that whenever i was making the page smaller for the small screens the page was breaking and the layout was breaking badly .
## My Fix - 
So the mess was already there but now to cover it all up i used **lg** for big screens and **sm** for smaller screens so that the page changes become dynamic and also deleted all the unnecessary hardcoded sizes and positions so that the page becomes responsive and at last with a ton of trial and error i finally made it
