# The journey 
## The Beginning - 
so the journey started when i wanted to make my very own person site where i wanted to store all the things that i am curious about also i wanted to learn a ne framework to make my project scaleable and hence i made it as well as mastered React Well 
## The Problems - 
In this Journey the main problem that i faced was to maintain Page Layout with the dynamic sections i mean how do i maintain the page layout when i started to add many sections dynamically ..
## My Mistakes - 
For The main Page where i have stored my intro the My Hobbies Section . There to place things at plae like the plant photos the section i mostly used hardcoded position using **Relative or Absolute** attributes and fixed Width and height all over the places now what happend was that whenever i was making the page smaller for the small screens the page was breaking and the layout was breaking badly .
## My Fix - 
So the mess was already there but now to cover it all up i used **lg** for big screens and **sm** for smaller screens so that the page changes become dynamic and also deleted all the unnecessary hardcoded sizes and positions so that the page becomes responsive and at last with a ton of trial and error i finally made it 
## My Learnings - 
1. To Make the Pages Responsive never use hardcoded positions such as top: bottom: let the page flow naturally .
2. To make the Project Scaleable Name your components with their exact task to remember where it belongs to.
3. Make it exist first modify it later

### Developement 
1. clone the source code to your device 
```sh
https://github.com/arpan832/personal_site && cd personal_site 
```
2. Install Project Dependencies
```sh
npm install 
```
3.Run the project 
```sh
npm run dev
```
4.Build the site to 'dist/'
```sh
npm run build
```
